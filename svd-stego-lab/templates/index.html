About stegoLab

The Science of Invisible Communication & Forensic Detection

What is Steganography?

Derived from the Greek steganos ("covered") and graphein ("writing"), steganography is the practice of concealing secret information within an ordinary, innocent-looking carrier file—such as a digital photograph—in such a way that no one suspects anything is hidden at all.

Unlike cryptography, which scrambles a message to make it unreadable but openly advertises its existence, steganography hides the very fact that a communication is taking place.

How the Techniques in stegoLab Work

1. Bit-Plane LSB (Least Significant Bit)

Digital images represent pixels using RGB color channels, each typically 8 bits deep (values 0–255). The lowest bit (Bit 0) carries the smallest numerical weight (±1 intensity level). Replacing the LSB of pixels with secret bits causes visual changes imperceptible to the human eye, yet recovers 100% of the hidden payload upon extraction.

2. SVD QIM (Singular Value Decomposition)

Rather than altering spatial pixel values directly, Singular Value Decomposition decomposes an image block A into UΣVT, where the singular values Σ = diag(σ1, σ2, …) describe the primary geometric energy of the block.

stegoLab applies Quantization Index Modulation (QIM) to the dominant singular value σ1, shifting it to the nearest lattice point corresponding to a 0 or 1 bit with step Δ. This method offers higher resistance against mild noise and compression.

3. Machine Identification Codes (MIC / Printer Tracking Dots)

Color laser printers subtly encode secret tracking dots across pages to identify the specific printer serial number, date, and exact timestamp of printing. stegoLab implements an authentic 8-row binary dot matrix with green separator columns and corner alignment brackets (┌ and ┴), allowing digital images to carry indelible watermarks and provenance records.

4. Multi-Scale Blind Steganalysis

To detect hidden payloads without knowing the secret key, stegoLab performs multi-scale statistical analysis:

  • Lattice Resonance Spectrum R(Δ): Measures periodic clustering of singular values to detect QIM steps.
  • Calibrated Chi-Square (χ2): Identifies frequency equalization anomalies between adjacent pairs of values (PoVs) characteristic of LSB overwriting.
  • Direct Framing Probe: Verifies structured Reed-Solomon protected headers.

Privacy & In-Memory Execution

Everything in stegoLab executes purely in volatile memory (RAM). Uploaded images, payload files, and secret keys are never written to server disks or sent across external networks.
